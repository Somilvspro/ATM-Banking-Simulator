# ATM Banking Simulator Using C

## About
A basic ATM Banking Simulator developed using C.

## Features
- PIN Verification
- Balance Enquiry
- Cash Withdrawal
- Cash Deposit
- Mini Statement
- Change PIN

## Technologies Used
- C Programming
- GCC Compiler
- VS Code

## Default Login
Demo PIN: 1234
Initial Balance: Rs. 5000

## How to Run

Compile:
gcc atm.c -o atm

Run:
./atm
